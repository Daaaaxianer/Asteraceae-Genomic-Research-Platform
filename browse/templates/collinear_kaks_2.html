Syn-Blocks

{#   Annotated genes were used as input to compare chromosomes within a genome or across genomes. First, we performed a mutual search of protein sequences for potential homologous genes by BLASTP software. And we set stringent parameters e values <1e-5 and scores >100. Some uncertainties could be excluded by the set stringent parameters. Next, information on homologous genes was used as input and collinearity of homologous gene pairs was located by using#} {# ColinearScan and McScanX software. The Ks of collinear gene pairs was calculated by the Nei–Gojobori approach implementing the Bioperl statistical module (https://bioperl.org).#}   In the Syn-Blocks interface, we provided pairwise genomic synteny blocks (SBs) and flexible tools for visualizing and analyzing evolutionary relationships between SBs. Using ColinearScan and McScanX for GenS inference, we detected 8,944,924 SBs from 17,203 pairwise genome comparisons, including 125,506,348 synteny gene pairs (SGPs). We calculated the nonsynonymous (Ka) and synonymous (Ks) substitution rates for each SGP, along with the median and mean values for each SB. Users can flexibly analyze specific chromosomes, and options like 'Block search' and 'Draw Ks peaks' allow easy identification of Ks peaks related to key evolutionary events.

# 文件下载 API

用户仍然点击原来的下载按钮，无需注册、登录、输入口令或复制参数。Django、数据库及生物信息学计算程序沿用现有版本。

- 公开数据和示例：`/api/download/public/<source>/<path>`。
- 分析结果：`/api/download/result/<path>`，根据浏览器自动携带的随机标记或文件专属链接检查访问权限。
- 页面预览和图表数据：`/api/files/public/...`、`/api/files/result/...`，保留内嵌显示和字节范围读取。
- 现有工具导出：`/api/download/` 下复用原计算和导出函数。
- 浏览器生成的表格/图片：`POST /api/download/export/`，临时回传文件，单次上限 16 MiB，不持久保存。
- 内嵌 SequenceServer 的两个下载操作由固定本机服务转发；JBrowse 数据文件走公开读取 API。

`static` 继续提供页面脚本、样式、字体和界面图片。公开科研数据目录及 `file_keep` 不再直接提供静态文件。平台尚未发布，旧下载入口返回 404，不迁移历史结果归属，也不删除历史文件。

新结果目录创建时，在项目私有目录 `.api_download_owners` 中记录随机访问标记的摘要和文件链接密钥，不新增数据库表。文件链接默认 7 天有效，可以在另一台设备打开；同一浏览器持有的标记也可访问自己的结果。单个文件链接不能改名读取同一目录内的其他文件。标记不代表真实个人身份，日志只能追踪请求与调用来源，不能证明操作者的实名身份。

统一入口检查已发布目录、路径边界、请求来源、速率和并发，记录请求编号、状态码等信息。日志不记录查询字符串中的访问标记或 API 密钥。Nginx 日志记录实际传输字节数。浏览器自动适配旧按钮、表单、Blob 和 FileSaver 下载。

回滚须同时恢复备份中的应用文件与对应 Nginx 配置；源服务的防火墙规则仅涉及本项目的 8457、8222、8515 端口，不影响 SSH 与 HTTPS。隔离测试使用虚拟数据库后端，不连接生产数据库。

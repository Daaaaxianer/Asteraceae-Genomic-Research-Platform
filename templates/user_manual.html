1. Home

The Home portal serves as the main interface, intuitively presenting the platform's overall resource distribution and quick links to featured resources, offering users a comprehensive overview and fast access experience.

This interface includes an AGRP introduction video, quick-access links to various resources, 62 window-style tool links, 9 genomic analysis pipelines and related software links, 156 genomic resource entries, AGRP update logs, citation methods for AGRP and our previous Asteraceae research articles, and links to publications citing our prior Asteraceae research.

2. Genomics

The Genomics Portal integrates the most comprehensive genomic and annotation resources. We have developed a system fully linked to AGRP-identifiers, enabling users to freely access relevant data resources and conduct integrated exploration across functional interfaces.

2.1 Genome

The Genome interface displays taxonomy, genome size, number of chromosomes, assembly level, data source, sequencing platform/method, assembly method, date, and reference links for 156 genomes (150 Asteraceae genomes and 6 outgroups).

It also highlights the 59 species (53 Asteraceae and 6 outgroups) used in the AGRP analysis. Users can freely select gene regions on chromosomes across different species and download gene CDS and PEP sequences.

2.2 JBrowse

The JBrowse interface provides visualization, browsing, and analysis of data for 59 species.

2.3 GO-annotations

The GO-annotations interface provides 23,959,751 annotation entries from the InterProScan software across 59 species. Users can query relevant annotation information in the AGRP database by searching for sequences or AGRP-IDs of corresponding species, with the freedom to select the scope of the query database.

2.4 KEGG-pathways

The KEGG-pathways interface provides 921,857 KEGG annotations across 59 species. Users can query relevant annotation information in the AGRP database by searching for sequences or AGRP-IDs corresponding to the target species.

2.5 Regulatory Proteins

The Regulatory Proteins interface provides 262,108 annotated entries across 59 species. Users may freely select the species, Regulatory Protein type, and specific families within different types for querying.

2.6 N6-methyladenosine (m6A)

The N6-methyladenosine (m6A) interface provides 2,129 N6-methyladenosine modifications across 59 species. Users can freely select the species to query, the Regulatory Factors type, and different families within each type.

2.7 Gene duplication type

The Gene Duplication Type interface provides duplication information for 5,575,472 genes across 59 species. Users can search for relevant information in the AGRP database by entering the sequence of the target species or its AGRP-ID.

2.8 Transposable elements

The Transposable Elements interface provides annotation information for 187,648,748 TEs across 53 Asteraceae genomes. Users can view the total number of TEs in each species, detailed counts by classification, and download complete annotation data for each species.

3. Geno-Syn

The Geno-Syn portal encompasses the largest-scale genomic synteny analysis, ancestral genomes, whole-genome orthologs, and trait-associated gene families, empowering users to delve into genome recombination and functional innovation driven by whole-genome duplication within Asteraceae plants.

3.1 Aster-Blocks

The Aster-Blocks interface provides 59 x 59 = 3,481 species-specific and interspecies resources related to species synteny obtained via ColinearScan and MCScanX.

Users can download whole-genome alignment data or freely select different chromosomes across various species for comparison. They can obtain and download synteny information, visualize synteny using the online Genome Synteny Viewer tool, and generate Ks peak distribution plots with Draw Ks peak.

3.2 Aster-Dotplots

The Aster-Dotplots interface provides 59 x 59 = 3,481 BLASTP dotplots, BLOCK dotplots, and Ks dotplots within and between species. Users can download whole-genome alignment dotplots or freely select different chromosomes from various species for online comparison to obtain online visual dotplots.

3.3 Aster-Alignments

The Aster-Alignments subpage features four macro-matrix modules using Euptelea pleiosperma, Vitis vinifera, Arctium lappa, and Helianthus annuus as reference species. These modules encompass 1,450,041 AGRP-identifiers spanning 15 WGDs and 175 speciation events across six outgroups and 43 Asteraceae species.

3.3.1 Hean-MGAs

Hean-MGAs interface utilizes Helianthus annuus-based macro-matrices, allowing users to freely search sequences or AGRP-IDs across different species. If a gene exists within the macro-matrix, the interface will jump to its position in the macro-matrix list. Below, it displays the GFF information for all species genes within that list, along with a visual representation of the list achieved through DecoBrowse.

3.3.2 Arla-MGAs

Arla-MGAs interface utilizes Arctium lappa-based macro-matrices, with similar functionality for searching and visualization as Hean-MGAs.

3.3.3 Vivi-MGAs

Vivi-MGAs interface utilizes Vitis vinifera-based macro-matrices, providing sequence search and visualization capabilities using DecoBrowse.

3.3.4 Eupl-MGAs

Eupl-MGAs interface utilizes Euptelea pleiosperma-based macro-matrices, allowing users to freely search sequences or AGRP-IDs and visualize results.

3.4 Aster-Evogenes

The Aster-Evogenes interface provides 2,099,581 WGD-associated paralogs, speciation-associated orthologs, and single-copy genes across 59 species. Users can query relevant information in the AGRP database by searching for sequences of the corresponding species or by entering an AGRP-ID.

3.5 Aster-Ancgenome

The Aster-Ancgenome interface provides static and dynamic karyotype evolutionary trajectories of 29 ancestral evolutionary nodes and 29 representing species within genera.

3.6 Aster-Anccalling

The Aster-Anccalling interface provides download links for CDS, PEP, LENS, and GFF files across 29 ancestral genomes.

Users can perform online BLAST comparisons by selecting different ancestral nodes, either by providing protein sequences or uploading FASTA-formatted PEP, GFF, and LENS files for species genomes (file formats should follow the example files on this page). This process yields the karyotype of the target species genome.

3.7 Gene family

The Gene Family interface features four subpages: Aster-Orthogroups, Aster-Genefamilies, Aster-Rubbergenes, and Aster-Inulingenes, facilitating the identification and evolutionary research of Asteraceae trait genes.

  • 3.7.1 Aster-Orthogroups: Provides information on 104,001 orthogroups (OGs). Users can query by sequence or AGRP-ID, or click directly on a target OG.
  • 3.7.2 Aster-Genefamilies: Provides annotation information for 1,097,511 genes across 180 families in 59 species. Includes tools like Fami-Tree and Fami-Circos.
  • 3.7.3 Aster-Rubbergenes: Provides annotation information for 5,059 genes across 21 rubber synthesis-related families in 59 species.
  • 3.7.4 Aster-Inulingenes: Provides annotation information for 1,079 genes belonging to the GH32 family across 59 species.

4. Multi-Omics

The Multi-Omics Portal provides extensive transcriptomic, metabolomic, and pan-genomic data resources for identifying genes associated with important traits in Asteraceae plants and elucidating their origins.

4.1 Aster-Transcriptome

The Aster-Transcriptome interface provides gene expression quantification results across 20 species and various tissues. Users can search for relevant information in the AGRP database by entering sequences or AGRP-IDs for specific species and selecting an expression index (FPKM/TPM).

4.2 Aster-Metabolome

Aster-Metabolome integrates the largest database of Asteraceae secondary metabolites to date, comprising two subpages:

4.2.1 Aster-Metabolomics

Contains 17,541 compounds from 1,500 species, linked to 257,590 candidate enzyme genes. Users can query by PubChem CID.

4.2.2 Aster-Floralscent

Integrates 812 volatile organic compounds produced by floral organs across 87 plant species, linking them to 26,858 candidate genes. Users can query by PubChem CID.

4.3 Aster-Pangenome

The Aster-Pangenome interface provides 952 pangenome information for 15 species.

5. Aster-Infor

The Aster-Infor portal aggregates species information, agronomic knowledge, literature, and external database links to support innovative research and breeding decisions within the Asteraceae family.

5.1 Aster-Encyclopedia

Provides images, genome size, chromosome number, assembly quality, gene content, TE content, species descriptions, and genome sequencing references for 82 species. Among these, 29 species also provide genome karyotypes.

5.2 Aster-Agroecology

Provides images, morphological features, cultivation methods, pest management, and applications for 122 species.

5.3 Aster-Exterdata

Provides access to 56 external databases, including 9 Asteraceae-related databases, 14 comprehensive resource databases, and 33 tool-based databases.

5.4 Aster-Literature

Provides access to 30,416 Asteraceae-related publications from the past three decades. Users can click on the DOI or PMID to navigate to the original article interface or the PubMed interface.

6. Bio-Tools

6.1 Web-Tools

Web-Tools comprises 62 user-friendly online tools. The All Tools interface provides an overview of all tools, allowing users to click on any tool to navigate directly to its online interface.

Users can also access different tool interfaces based on five functional categories: Sequence similarity comparison and homology visualization, Inference and analysis of gene synteny, Gene structure and visualization, Phylogenetic and expression analysis of genes, and Calculation Tools.

6.2 Bio-Software

Bio-Software contains 72 tools available for local download. Users can click "reference" to view literature related to the software, download installation packages via "download," and access AGRP for software download methods, usage guidelines, and common precautions.

7. Aster-Stats

The Aster-Stats interface provides 16 interactive charts. Users can choose to view them online or click on the data to jump to the analysis interface.

8. Submit-Projects

The Submit-Projects interface enables users to upload all resources beneficial to Asteraceae genome analysis—including genomes, transcriptomes, metabolomes, and pan-genomes—in compliance with transmission protocols, ensuring the continuous updating of the AGRP.

9. AGRP-Switch

AGRP-Switch provides an integrated exploration of diverse omics data resources within the AGRP database. Users can retrieve all data results associated with omics interfaces across the platform with a single click by entering a gene's AGRP-ID or PEP.
